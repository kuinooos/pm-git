# 欧盟碳边境调节机制 (CBAM) 政策摘要

## 1. CBAM 概述

欧盟碳边境调节机制（Carbon Border Adjustment Mechanism, CBAM）是欧盟根据《欧洲绿色协议》设立的碳关税制度，旨在防止"碳泄漏"——即企业将高碳排放生产转移到环保法规较宽松的国家。

CBAM 法规编号为 Regulation (EU) 2023/956，于2023年5月10日通过，2023年10月1日正式进入过渡期。过渡期持续至2025年12月31日，期间仅需申报碳排放数据，无需实际缴纳碳关税。2026年1月1日起进入正式执行期，开始逐步征收碳关税。

## 2. CBAM 管控品类

CBAM 目前覆盖以下六大类产品：

1. **水泥** - HS Code: 2523 - 包括硅酸盐水泥、熟料等
2. **电力** - HS Code: 2716 - 进口电力
3. **肥料** - HS Code: 2821, 3102 - 包括氨、硝酸铵、尿素等
4. **钢铁** - HS Code: 7208, 7213, 7214, 7225, 7308 - 包括热轧钢、钢筋、钢板等
5. **铝** - HS Code: 7601, 7604, 7605, 7606, 7616 - 包括原铝、铝型材、铝板等
6. **氢气** - HS Code: 2804 - 自2026年起纳入管控

## 3. CBAM 排放计算方法

### 3.1 直接排放 (Scope 1)
指生产设施在生产过程中直接产生的温室气体排放，包括：
- 燃料燃烧排放（如天然气、煤炭燃烧）
- 工艺排放（如水泥生产中的石灰石煅烧）
- 泄漏排放

### 3.2 间接排放 (Scope 2)
指生产过程中消耗外购电力产生的排放。对于铝和氢气，间接排放也需要计入。

### 3.3 CBAM 基准值
CBAM 为每个品类设定了基准排放强度：
- 铝: 15.2 tCO2e/吨
- 钢铁: 1.85 tCO2e/吨
- 水泥: 0.72 tCO2e/吨
- 化肥: 2.1 tCO2e/吨
- 氢气: 9.0 tCO2e/吨
- 电力: 0.42 tCO2e/MWh

## 4. 免费配额逐步退坡

在正式执行期（2026-2034），CBAM 配额将逐年退坡：
- 2026年: 97.5% 免费配额
- 2027年: 95% 免费配额
- 2028年: 92.5% 免费配额
- 2029年: 90% 免费配额
- 2030年: 85% 免费配额
- 2031年: 77.5% 免费配额
- 2032年: 70% 免费配额
- 2033年: 57.5% 免费配额
- 2034年: 50% 免费配额（钢铁过渡性配额）
- 2034年后: 0% 免费配额（全面征收）

## 5. CBAM 申报义务

在过渡期（2023.10-2025.12），进口商必须每季度提交 CBAM 报告，包括：
- 进口产品总量
- 直接碳排放总量 (Scope 1)
- 间接碳排放总量 (Scope 2, 仅限铝和氢)
- 产品在原产国已支付的碳价
- 如适用，免费配额计算

正式执行期后，进口商需购买 CBAM 证书来覆盖排放量，证书价格基于欧盟 ETS 碳价。

## 6. 合规风险点

出口企业需特别注意以下合规风险：
1. **数据质量风险** - 碳排放数据不准确导致申报错误
2. **碳成本转嫁风险** - 碳关税增加出口成本
3. **供应链追溯风险** - 需要追溯上游供应商的碳排放数据
4. **技术计算风险** - 排放因子选择不当或计算方法不符合欧盟要求
5. **法规更新风险** - CBAM 规则和管控品类可能扩大
