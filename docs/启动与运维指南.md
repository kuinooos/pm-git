## 一、环境准备

### 1.1 系统要求

| 依赖 | 版本要求 | 说明 |
|------|----------|------|
| Python | 3.10+ | 需要支持 `|` 联合类型语法 |
| Redis | 7.x | 缓存 + Celery broker（可选，不可用时自动降级） |
| Git | 任意 | 克隆仓库 |

### 1.2 安装 Python 依赖

```bash
cd backend
pip install -r requirements.txt
```

### 1.3 配置环境变量

```bash
cd backend
cp .env.example .env
```

编辑 `.env`，必填项：

```ini
# 必填：LLM API Key
LONGCAT_API_KEY=your_api_key_here

# 必填：JWT 密钥（生产环境请换成随机字符串）
JWT_SECRET_KEY=your-random-secret-key

# 可选：Redis 连接（不填则缓存自动降级禁用）
REDIS_URL=redis://localhost:6379/0
```

### 1.4 （可选）初始化 RAG 知识库

如果首次运行或知识库文档有更新：

```bash
cd backend
python -m src.domain.rag
```

这会加载 `backend/data/raw_documents/` 中的政策文档，完成向量化并存入 Milvus。

## 二、启动方式

### 方式一：全 Docker 启动（生产推荐）

```bash
cd backend

# 1. 启动后端 + Redis
docker compose up -d

# 2. 启动 Celery Worker（异步审计任务）
docker compose --profile worker up -d

# 3. 启动 Chainlit 前端（可选）
docker compose --profile chainlit up -d

# 查看状态
docker compose ps
```

**Profile 说明：**

| 命令 | 启动的服务 | 端口 |
|------|-----------|------|
| `docker compose up -d` | app + Redis | `8008` |
| `docker compose --profile worker up -d` | + celery-worker | `8008` |
| `docker compose --profile chainlit up -d` | chainlit + Redis | `8009` |

### 方式二：分别手动启动（开发推荐）

#### 2.1 启动 Redis（可选）

```bash
# Docker 方式
docker run -d --name redis -p 6379:6379 redis:7-alpine

# 或直接使用本地 Redis
redis-server
```

> Redis 不可用时系统自动降级——缓存禁用、Celery 异步不可用，其他功能不受影响。

#### 2.2 启动 FastAPI 后端

```bash
cd backend

# 方式 A: 模块路径启动
uvicorn src.api.app:app --host 0.0.0.0 --port 8008 --reload

# 方式 B: main.py 启动
python main.py
```

启动成功后会打印：

```
============================================================
  Carbon Compliance Audit Agent - API starting
============================================================
  Docs: http://localhost:8008/docs
  ReDoc: http://localhost:8008/redoc
  [UP] Redis
  Celery broker: redis://localhost:6379/1
============================================================
```

#### 2.3 启动 Chainlit 前端

从**项目目录**运行：

```bash
chainlit run app.py -w
```

访问 http://localhost:8000 进入对话界面。

> **注意**：Chainlit 默认端口是 8000，与后端 8008 不冲突，两者可同时运行。

#### 2.4 启动 Celery Worker（可选，异步审计需要）

```bash
cd backend
celery -A src.infrastructure.celery_app worker --loglevel=info --concurrency=2
```

## 四、API 使用流程

### 4.1 获取认证 Token

```bash
curl -X POST http://localhost:8008/api/v1/auth/token \
  -H "Content-Type: application/json" \
  -d '{"username": "admin", "password": "admin123"}'
```

返回：

```json
{
  "access_token": "eyJhbGciOi...",
  "token_type": "bearer",
  "expires_in": 1440
}
```

### 4.2 发起审计任务

```bash
curl -X POST http://localhost:8008/api/v1/audit/start \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <你的token>" \
  -d '{
    "bom_data": {
      "product_name": "铝合金型材",
      "hs_code": "7604",
      "weight_kg": 60000,
      "material": "铝",
      "origin_port": "深圳",
      "destination_port": "汉堡",
      "transport_mode": "sea"
    },
    "target_country": "EU"
  }'
```

返回 `thread_id`，工作流运行到人工审查节点后暂停。

### 4.3 查询审计状态

```bash
curl http://localhost:8008/api/v1/audit/status/{thread_id} \
  -H "Authorization: Bearer <你的token>"
```

### 4.4 人工审批

通过审查：

```bash
curl -X POST http://localhost:8008/api/v1/audit/approve \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <你的token>" \
  -d '{"thread_id": "<thread_id>", "approved": true, "feedback": "审查通过"}'
```

驳回：

```bash
curl -X POST http://localhost:8008/api/v1/audit/approve \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <你的token>" \
  -d '{"thread_id": "<thread_id>", "approved": false, "feedback": "数据有误需重审"}'
```

### 4.5 检索政策知识库（公开接口）

```bash
curl -X POST http://localhost:8008/api/v1/rag/search \
  -H "Content-Type: application/json" \
  -d '{"query": "CBAM 铝制品碳关税政策", "top_k": 3}'
```

### 4.6 上传政策文档（需要认证）

```bash
curl -X POST http://localhost:8008/api/v1/rag/upload \
  -H "Authorization: Bearer <你的token>" \
  -F "file=@/path/to/policy_document.pdf"
```

## 五、Chainlit 前端使用

### 5.1 启动

从**项目根目录**运行：

```bash
chainlit run frontend/app.py -w
```

访问 http://localhost:8000。

### 5.2 三种交互模式

| 输入 | Router 判定 | 行为 |
|------|------------|------|
| "你好，你会做什么" | `chat` | 直接 LLM 回复，**不启动工作流** |
| "CBAM 铝制品关税政策是什么" | `policy_query` | 单步 RAG 检索，返回政策条文 |
| "60吨铝合金 HS7604 深圳→汉堡 EU CBAM审计" | `carbon_audit` | 启动看板+监督者工作流 |

### 5.3 碳审计操作流程

1. 在对话框输入审计需求，例如：

   > 我们有 60 吨铝合金型材，HS Code 7604，要从深圳海运到德国汉堡，生产用电 1200 MWh。请做 EU CBAM 合规审计。

2. 系统自动执行：
   - 🧭 **Router** → 识别为 carbon_audit
   - 🔍 **信息萃取 Agent** — 提取产品、HS Code、重量、路线
   - 📜 **政策判定 Agent** — RAG 检索 CBAM 铝制品政策
   - 🧮 **排放计算 Agent** — 计算 Scope 1/2/3 碳排放
   - ⚖️ **合规风控 Agent** — 对标基准值，生成风险分析
   - 👁️ **Supervisor** → 所有 Agent 完成，等待人工审查
   - ⏸️ **暂停** → 展示审查摘要

3. 审查数据后，点击 **✅ 通过审查** 或 **❌ 驳回**

4. 通过后自动生成审计报告并支持 **PDF 下载**
