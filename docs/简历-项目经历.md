全球碳关税合规审计多智能体系统 | FastAPI, LangGraph, LangChain, Chainlit, Pydantic, Milvus, Redis, Celery &nbsp;&nbsp;&nbsp;&nbsp;2025年07月

设计基于 LangGraph StateGraph 的多智能体编排架构，通过看板(Blackboard)共享状态与监督者(Supervisor)调度机制，实现 6 个领域 Agent 的自主协作，并引入 Human-in-the-Loop 断点实现关键节点的暂停与人工审批恢复。

构建了智能体工作流中的 Router 意图解释器，利用 LLM 对用户自然语言进行语义分类，自动分流至闲聊、政策检索、碳审计三条处理路径，并通过规则优先匹配和异常降级策略确保路由的鲁棒性。

实现了混合检索增强生成(RAG)管道，整合 Milvus 向量语义搜索与 BM25 关键词检索，通过 RRF 融合排序和 CrossEncoder 重排序模型提升政策文档召回精度，有效增强审计 Agent 的上下文质量。

搭建了基于 Celery + Redis 的异步任务队列，将碳排放全链路计算从 HTTP 请求链路解耦，配合 LangGraph SqliteSaver Checkpointer 实现工作流状态的持久化与断点恢复，保障长耗时审计任务的可靠性。
